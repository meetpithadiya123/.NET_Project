MOLLA GAMING STORE
==================
Open ../index.html in a browser.

Structure:
- index.html is the only file in the root.
- CSS, JavaScript and all local artwork are inside assets/.
- No build step is required.

Features:
- Responsive storefront layout based on the provided design reference.
- Category filtering and product search.
- Hero slider.
- Wishlist and cart counters with a mini-cart panel.
- Newsletter and sign-up interactions.
